# 🧮 Calculator

A simple, neumorphic-style Calculator built using **HTML, CSS, and JavaScript** for basic arithmetic operations.

---

## ✨ Features

- Basic operations: addition, subtraction, multiplication, division, percentage
- AC (clear) and DEL (backspace) functionality
- Clean, dark neumorphic UI design
- Built with vanilla JavaScript — no external libraries

---

## 🛠️ Tech Stack

- **HTML** — structure
- **CSS** — neumorphic styling and layout
- **JavaScript** — calculation logic
